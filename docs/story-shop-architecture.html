Big picture

Shop = story-internal screen family. No shell route. State machine stays reduceStory; economy stays inside StoryState, saved with everything else (schema v2). Cross-domain jumps (deck builder, main menu) = location.hash writes; boundaries untouched.

Commands (all guarded in reduceStory)

open-shopleave-shop shop-navigate {greeting|browse|sell} buy-packs {setId, count} buy-single {code, rarity} view-set-cards {setId} open-boosters {picks, cards, mode} finish-opening acknowledge-opened sell-cards {items}

UI cannot mint DP or cards: every mutation validated (wallet, ownership, unlock, integer counts). RNG stays outside the reducer — open-boosters receives generated cards; tests seed the generator.

Data (ADR-035, grill-confirmed)

  • Sets: first 50 TCG English booster sets (LOB 2002 →) in public/story/shop-sets.v1.json, hand-assembled once, no pinning ceremony. Per card: {code, name, rarity}. First 3 sets start released.
  • Delivery: lazy fetch on first shop entry → structural validation → Cache Storage (story-shop-data, cache-first) → fully offline afterwards (PWA rule). Never bundled into the story JS chunk.
  • Coverage: full real lists shown; packs/singles grant any listed card into collection[code]. Missing art → placeholder tile until the image pipeline covers the code (plan T14, main-lane). Packaged cards outside the 50 sets: invisible test data.
  • Pack: 9 cards = 8 commons + 1 rare-or-better · 100 DP. Singles: 4× sell price once the set is released (common 40 DP).
  • Rarity: printed rarity from set data (highest across printings in a set) → fallback ordered inference (ATK ≥ 3000 → secret; extra deck → ultra; ritual / ATK ≥ 2000 → super; typed S/T or lv ≥ 5 effect → rare; else common) → common.
