Invariants

  • Halo colour is meaning: blue --seat-you, red --seat-opponent, teal --accent focus, gold --selected hairline for the default — tokens in src/styles/tokens.css.
  • Presentation never determines legality — legal/blockReason arrive computed from the host's authority (core architecture rule).
  • Floating elements carry explicit [hidden]{display:none} overrides (prototype trap: author display beats the UA hidden rule).
  • Illegal decks: story lists them disabled with the reason; free play never lists them (listing already drops them).
