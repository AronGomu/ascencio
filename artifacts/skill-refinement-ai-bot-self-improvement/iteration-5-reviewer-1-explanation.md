# Explanation from reviewer 1 for comprehension review

## 1. Outcome and scope

Improve one supplied target bot against frozen opponents, including its starting self. Optional opponents, owner limits and compatible checkpoint refine setup. Only target AI changes; preserve engine, decks, legality and information boundaries. Success delivers accepted source, verified paired results and history; unchanged acceptance is honest success when no edit qualifies. YAML permits implicit invocation.

## 2. Process overview

Prepare → Evaluate → Decide → Analyze → Replay → Assemble loops through candidates. Analysis follows every evaluation decision, including the last. Decision ceiling or no qualifying replay edit leads to Deliver; incidents can suspend any active stage. Only diagnosis is delegated.
