Prototype notes — what this asks of the code
  • One screen, two scopes. A single component takes scope: "free-play" | "story". It decides three things: which library is listed, whether the opponent seat is choosable, and where the deck-builder button routes — #/free-play/decks vs #/story/decks.
  • Free Play lists bundled presets plus the free-play library, already filtered to playable decks by listSelectableDecks. The opponent seat is choosable and borrows the same list.
  • Story lists the save's decks only, keeps illegal decks visible but disabled with the reason (preBattleBlock semantics), and shows the encounter's fixed opponent — portrait, name, their deck, locked.
  • Ordering is orderDeckLibrary unchanged: default deck first, favourites next, then the chosen sort. Toggling a star re-sorts live.
  • New data: DeckRecord has no cover today. It needs one field — coverCardCode?: number — defaulting to the deck's first Extra card, else its first Main card, so every existing deck gets an illustration without an edit.
  • Art in this file is authored geometry. Shipping swaps each <use> for the cover card's cropped image from the pinned snapshot.
  • Same tile in both places. The "Deck builder library" view renders the identical tile component; only the surrounding frame and the row's action differ (open vs select).
