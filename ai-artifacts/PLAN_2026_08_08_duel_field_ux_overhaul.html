Goal

App today = board buried in a column of panels. App after = board is the app. Every decision affordance lives on or over the field: hover chips, drag-and-drop, corner End turn, status pills, preview panel. Chrome shrinks to one menubar button.

Success = all 18 items shipped, npm run check green, duel completable mouse-only and keyboard-only.

Hard boundary

src/worker/** is untouched. ocgcore stays the sole authority for legality, effects and results. Everything here is presentation.

Locked decisions

Prompt routing

Workspace hidden. A prompt that cannot be answered on the field opens a modal dialog. No close button — the engine is waiting.

Inspector

Deleted. The preview panel is the only card-detail surface.

Drag halo

Local guess, engine reconciles. Drop sends the action, arms the zone, auto-answers the follow-up selectPlace. A miss degrades to the real prompt.

data-cy

Every element under src/app/, unique, enforced by a static unit test.

Action words

Derived from choice.action, not engine text. Two words only where one would lie: Special Summon, Change Position.

Status panel

Panel and snapshot line dropped. Loading becomes a top overlay. Error, result and warning panels stay.

End turn

Always mounted bottom-right, orange, disabled unless the engine offers endPhase. Label follows the phase.

Preview panel

Fixed 22rem, same row, same height, sticky content, stacks below the field under 64rem.

Life points

HUD hides by default and takes LP with it. Two LP pills return to the field.

Drag handshake

The engine never ships action and zone together. One gesture, three messages, one safe fallback.

sequenceDiagram
  participant U as Player
  participant F as DuelField
  participant S as Duel store
  participant W as Worker / ocgcore
  U->>F: pointerdown + move > 8px on hand card
  F->>F: placementZoneCandidates(action, board) — local guess
  F-->>U: orange halo on candidate zones
  U->>F: pointerup over a candidate
  F->>S: armPlacementIntent(zoneId)
  F->>S: chooseChoice(actionChoiceId)
  S->>W: respond(promptId, [actionChoiceId])
  W-->>S: prompt selectPlace (min 1, max 1)
  alt armed zone is offered exactly once
    S->>W: respond(promptId, [placeChoiceId])
    Note over S,W: single gesture completes
  else engine offered other zones
    S-->>U: real zone prompt, true highlights
    Note over S,U: intent dropped, no bad response
  end

Risks

E2E churn

e2e/duel-smoke.spec.ts is 1869 lines asserting against panels this plan deletes. Every ticket fixes its own selectors in the same commit. Deferring guarantees a red gate later.

Screen reader

T3 deletes two live regions the screen-reader review credits. User-directed, recorded in ADR-003. App-level announcements survive; per-move field narration does not.

Optimistic halo

T10's halo is a guess. It may light a zone the engine rejects or omit one it allows — field spells especially. Cost is one extra prompt, never a wrong response.

Target size

Chips sit below the 44px pointer-target guidance by design. The card's own 44px target and the keyboard path stay intact.
