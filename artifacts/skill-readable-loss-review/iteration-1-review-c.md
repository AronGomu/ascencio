# Explanation from reviewer C for fresh candidate comprehension

## 1. Outcome and scope

I would improve the required target `ai-bot` against frozen opponents including its starting version, producing accepted source, reproducible paired results and compact history even if no edit qualifies. Optional opponents, owner limits and a compatible checkpoint refine the run. I may change only target AI; decks, engine, legality and hidden information remain protected. Completion requires required evaluation decisions and analysis, verified accepted export and checked reporting, or an explicitly incomplete suspension/closure with preserved continuation evidence.

## 2. Process overview

I follow the stage controller while owning tools persist state and I verify semantic gates: Prepare → Evaluate → Decide → Analyze, then either Deliver or Replay → Assemble → Evaluate. Baseline is evaluated unchanged and recorded without consuming a candidate decision. Every evaluated candidate, including final/rejected versions, is analyzed. Readable loss review can overlap finalized evaluation slices under admitted pipeline envelopes; global consolidation waits for evaluation and decision. Replay validates isolated corrections, assembly combines passing edits, and paired evaluation alone authorizes promotion. Stops override every transition.
