Invariants this flow protects

  • One derivation, two surfaces. The editor cannot offer a card the picker withholds, because both read the same memoized catalog.
  • The engine stays authoritative. Nothing here decides legality; the Worker still loads the card data and scripts it needs and still refuses what it cannot run.
  • The snapshot stays one verified unit. Files are copied because the manifest declares them, and build:verify re-checks byte length and digest for every one.
  • Art is decoration. A missing image is a placeholder, never a validation error and never a reason to withhold a deck.
