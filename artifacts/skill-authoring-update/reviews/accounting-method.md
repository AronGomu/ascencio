# Accounting method

Instructional characters are Unicode code points, including line endings, in every package `.md`, `.txt`, `.yaml` and `.yml` resource. The bot additionally counts 168 characters of executable-embedded instructions: the 84-character instructional comment and 84-character CLI usage text in its executable `.mjs`; executable-only implementation is excluded. Physical bytes count every file in the package. No resources are removed, moved, generated or hidden from these totals.

Shared external dependencies (project tools, runner document and global writing/authoring guidance) are unchanged and are not claimed as reductions. They remain required reads under their incoming conditions. Counts describe complete physical candidate packages, not an asserted reduction of the entire repository/dependency closure or one stage’s loaded context. Snapshots, explanations, audits, validation and reviews are review artifacts and excluded from package totals.

The baseline is each authored source pinned in authored-source-hashes.json, not historical pre-promotion bot content. Added model defaults and automatic review requirements were already present in that baseline and are preserved; they are not counted as refinement savings or new behavior.

Final audit corrected an initial omission of CLI usage text. All bot iteration baselines and candidates were recounted with the same additional 84 characters; older raw counts are explicitly labeled pre-correction. No candidate/source edits or extra review rounds were needed for an accounting-only correction.
