# Explanation from reviewer A for prospective skill authoring

## 1. Outcome and scope

I would create or revise an agent skill that produces the requested observable outcome, preserves useful existing instructions, and respects the user's scope. Required information is the requested behavior and, for revisions, the existing package; optional details are inferred safely. Completion includes a usable authored package and a separately saved, five-iteration refinement candidate with evidence. This document explains prospective execution only; it performs no authoring or review delegation.

## 2. Process overview

I would read the candidate authoring package, its ordered guidelines, and supporting writing guidance before drafting. I would inventory behaviors, choose applicable template sections, write concrete dependent steps, and validate the result. Then one refinement child would run the linked refinement process for five iterations. Within each iteration, three fresh comprehension reviewers explain the candidate independently; comparison and minimal corrections repeat until misunderstandings are resolved. Review-generated edits stay inside that review rather than recursively starting authoring reviews.

## 5. Limits and accounting

| Resource/stage | Default limit | Override rule | Accounting | Action at exhaustion |
|---|---|---|---|---|
| Automatic refinement | Five iterations | Session instructions govern | Record each iteration separately | Deliver evidence; no automatic promotion |
| Correction review | Until no misunderstanding remains | Owner may stop | Distinguish wording from behavioral disagreement | Flag corrections lacking fresh review |
| Reduction target | Aspirational 25% | Readability and preservation dominate | Count all agent-facing instructions, references, configuration and generated copies | Retain necessary content |
