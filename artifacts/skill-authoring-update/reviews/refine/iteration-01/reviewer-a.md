# Explanation from reviewer A for prospective refinement execution

## 1. Outcome and scope

Given a required skill-folder path, I would produce a complete, shorter, readable sibling candidate preserving the source's intent, essential behavior, dependencies and output contracts. Optional inputs set priorities, retained requirements, iteration count, destination and review context. Success requires the requested iterations, relevant validation, fresh comprehension review without remaining misunderstandings, and delivery evidence. Source replacement requires a later separate explicit instruction.

## 2. Process overview

As orchestrator, I would read the complete input and applicable authoring guidance, establish its behavioral baseline and explain its execution. I would then simplify the candidate, validate it, obtain three independent explanations and correct misunderstandings. Verification and fresh review repeat until comprehension agrees; this inner loop sits inside the requested simplification iterations. Candidate edits remain within this review and do not start recursive authoring reviews.
