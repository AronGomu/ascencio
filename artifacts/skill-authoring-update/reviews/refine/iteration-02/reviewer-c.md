# Explanation from reviewer-c for candidate comprehension

## 1. Outcome and scope

Given a required skill folder, produce a complete, shorter sibling package preserving its intended outcome, essential behavior, dependencies and specified outputs. Optional priorities, retained requirements, destination, iteration count and review context shape the work. Success requires finishing the requested refinement iterations, correcting comprehension disagreements through fresh review, and delivering evidence without changing or promoting the source. This document describes that process; it does not execute it.

## 2. Process overview

The orchestrator first understands the incoming package and applicable authoring guidance, records its behavioral baseline and writes its explanation. Each iteration simplifies the candidate, verifies affected behavior and references, obtains three independent explanations, and repairs misunderstandings until the review gate passes. It then records counts and findings before starting another simplification iteration. Shared guidelines additionally require deletion audits and boundary comparisons, because reviewer agreement alone cannot detect obligations removed entirely.

## 5. Limits and accounting

| Resource/stage | Default limit | Override rule | Accounting | Action at exhaustion |
|---|---|---|---|---|
| Iterations | Five | User count | Record each completed iteration | Deliver after requested count |
| Reduction | Aspirational 25% | Preservation/readability prevail | All agent-facing instructions, references, configuration; relocation counts | Continue useful simplification; no forced deletion |
| Exclusions | Executable-only inputs and review artifacts | Instructional prose still counts | Separate physical package size | Report scope honestly |
| Models | GPT-6.1 Sol, low | Explicit user settings/documented override | Report actual supported settings | Unavailable required delegation/settings leaves review pending |
| Repair loop | Until no misunderstanding | Owner/session stopping instruction | Retain checks and rounds | Report unreviewed corrections if stopped |
