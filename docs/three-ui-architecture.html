Layout law

Story duel handoff

Invariants

Engine authority

  • Frozen vendor/ocgcore-wasm/0.1.2
  • Only the Worker owns WASM, protocol, scripts, handles
  • Main thread receives clone-safe projected state
  • Deck lists validated against the packaged snapshot before any session

Module boundaries

  • One public index.ts per domain
  • No deep cross-domain import
  • No shared/common/utils folder
  • Shell owns routes, stage, tokens, settings

Data safety

  • One durable store per owner
  • Versioned envelopes, exact-key parsing
  • Deck migration: copy → verify → delete
  • Quota, corruption, conflict are typed outcomes
