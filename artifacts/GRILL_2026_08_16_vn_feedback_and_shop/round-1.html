VN feedback + shop — settle the assumptions

A full plan already exists (13 tickets, 3 ADRs). It was written on 12 unconfirmed assumptions. Each question below shows the plan's current choice as Recommended — confirm or override; the plan and ADRs get patched from your answers. Check boxes, add precisions, hit Copy.

feedback-vn→General UI→Economy→Shop design→(round 2 if overrides)
1. Does “Open Pose Menu” mean the “Open pause menu” button?

Two feedback items hinge on this reading; if a real character-pose feature was meant, T1/T2 change entirely.

2. Where does the gear button sit on map / system screens?

Feedback says “same location as the dialog window” — the dialogue box spans the bottom, so the literal spot is ambiguous.

3. What does Hide UI hide?

Toggle button is agreed; unclear whether the utility bar itself should vanish with the dialogue.

4. Return-to-menu: VN only, or all domains now?

Feedback says “all interfaces”; but duel/deck belong to other branch lanes — including them makes this a cross-lane plan.

5. DP + collection: inside story saves, or separate persistent store?

Decides what loading a save does to your money and cards — the deepest gameplay consequence in the plan.

6. Top bar (DP · shop · deck): position and screens?

“At the top of the screen” leaves corner and screen coverage open; narrative's utility bar already owns the top-right.

7. Shop entry points?

Feedback names both a map location (test) and a top-bar icon “whenever available”; restrictions come later.

8. Prototype set catalog: how do ~120 packaged cards become “extensions”?

The pinned snapshot has no set membership; hundreds of real sets need a browsable index today and honest data later.

9. Pack size and price?

Start wallet is fixed at 1000 DP; pack economics set the whole pacing of the loop.

10. Sell price ladder (common fixed at 10 DP)?

Feedback fixes common = 10 and says infer the rest; the ladder decides whether selling dupes funds new packs.

11. Rarity source + halo palette?

Snapshot carries no rarity; something deterministic must color every card until real printing data exists.

12. “Open” animation: click-to-advance or timed?

Feedback wants an animation per pack and per card; the advance mechanism decides feel and testability.
