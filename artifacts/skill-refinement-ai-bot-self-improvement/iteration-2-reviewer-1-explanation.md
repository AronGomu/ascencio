# Explanation from iteration-2-reviewer-1 for refined AI bot self-improvement execution

## 1. Outcome and scope

Given a target bot package, optional additional opponents and optional owner limits, I would run reproducible paired evaluations to seek a strictly better target AI, retain the accepted source when improvement fails, and deliver verified history, existing-results ranking and accepted export. Only the target AI changes; the frozen starting AI always remains an opponent. Successful completion requires finishing planned decisions and their analyses or reaching the authorized no-validated-candidate stop, with checked consolidation; resource suspension is incomplete. This document describes execution without running it.

## 2. Process overview

I would prepare identities, budgets, calibration and slice ownership, evaluate baseline, decide, then delegate loss-only diagnosis. Each candidate comes from isolated replay-validated rules, followed by full paired evaluation and another decision and analysis. Ordinary improvement uses accepted source; regression repair uses the regressing candidate as replay and assembly source while retaining the accepted comparator. The loop closes at its completion conditions; interruption follows checkpoint recovery, while exhausted resources suspend it.
