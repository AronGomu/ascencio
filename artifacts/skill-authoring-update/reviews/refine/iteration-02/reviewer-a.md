# Explanation from reviewer A for candidate comprehension

## 1. Outcome and scope

Produce a complete, shorter, readable sibling skill package while preserving its intended behavior, dependencies and output contracts. The required input is a skill folder; priorities, retained requirements, iteration count, destination and review context are optional. Success requires the requested iterations, validation and fresh comprehension review, with evidence and a concise report outside the candidate. Source replacement is outside this process.

## 2. Process overview

The orchestrator reads the package and linked authoring guidance, records essentials and explains the incoming skill. It simplifies the candidate, verifies changes, obtains three independent explanations and repairs behavioral misunderstandings until review converges. It records counts and findings, then repeats simplification for the remaining iterations. Mutual authoring/refinement links supply requirements without recursively starting another automatic review.

## 5. Limits and accounting

| Resource/stage | Default limit | Override rule | Accounting | Action at exhaustion |
|---|---|---|---|---|
| Iterations | Five | User-requested count | Record each iteration | Deliver after completed count |
| Reduction | Aspirational 25% | Preservation/readability take precedence | Count all agent-facing instructions, references, configuration and generated copies | Continue useful simplification within iterations |
| Review loop | Until understood | Session/user stopping instructions | Record every correction/review | Report unreviewed corrections if stopped |
| Model | GPT-6.1 Sol, low | Explicit user settings | Report actual controls/settings | Unavailable required delegation/settings leaves review pending |

Executable-only source, inputs and refinement artifacts are excluded from instruction counts; instructional prose in code counts. Report physical package size separately. Relocation does not reduce total instructions; record authorized behavior changes separately from compression.
