# Explanation from reviewer B for prospective skill authoring

## 1. Outcome and scope

I would create or revise the requested agent skill, using the annotated template to express its observable goal, inputs, constraints, outputs and executable workflow. The user's requested behavior and existing useful instructions determine scope. Success requires a usable authored package, appropriate verification and a separate five-iteration refinement review, with honest reporting. The authored package remains intact during review; replacement requires a later explicit instruction.

## 2. Process overview

I would first read the ordered guidelines and supporting writing guidance, inventory behavior and resolve required inputs. I would then adapt the template, retain necessary dependencies and validate the result. After completing authoring, I would delegate refinement once for each changed skill. That child would simplify a separate candidate, verify it, obtain fresh comprehension explanations, repair misunderstandings and repeat through five iterations. Internal review edits do not start further authoring reviews.
