DS-3. Tiles are square (aspect-ratio 1/1) in a CSS grid. "Few" needs a number and "bigger" needs a cap, or the rule is unimplementable.

DS-4 says "move the star to top right" where the (removed) checkmark lived. Today there are TWO stars: gold default-deck star (top-left, not a button) and favourite toggle ☆/★ (right side, a button). Which one moves?

DB-3 and Map-1 both want a red bottom-left "Return to X" naming the previous screen. Neither the shell (hash routes) nor the story (screen state machine) records where you came from. The deck-select screen already renders "← Return to {backLabel}" — the label convention exists.

DB-4. A YDK import dialog already exists (paste + .ydk file, preview, unknown-code detection) but only from the Deck Library. Load (autosave restore) stays separate. What does Import do inside an open deck?

DB-5. Current "Sort A–Z"/"Sort by type" buttons mutate the deck's card order (undoable). The new select adds Level/Attribute/Monster-Type/ATK/DEF modes plus an asc/desc toggle.

7. Single click locks preview — lock vs hover priority

DB-6. Today hover updates the preview panel and click selects. If click "locks" the preview, hovering other cards must either be ignored or temporarily override the lock.

8. Red zone borders + (!) — error mapping and tooltip

DB-9. The ValidationIssues strip is removed. Errors must be attributed to main vs extra, and "(!)" needs a hover tooltip.
