Deck Selection Screen — implementation plan

2026-08-27 · 15 tickets · design source: docs/deck-selection-screen-design.md · prototype git show 7c34d05:artifacts/PROTOTYPE_duel_start_deck_selection.html

Goal

One shared Svelte screen (new domain src/deck-select/, ADR-055) replaces 4 screens: free-play match setup + seat, story pre-battle, deck-editor library. Success = all three run on it, check:headless + build:verify + e2e green.

In scope

  • Shared presentational lib: tile, kebab, screen, previews, mobile
  • New public entry + boundary registration (ESLint + frozen test)
  • 3 free-play AI personas + settings persistence
  • SelectableDeck widening (lists, updatedAt)
  • Story save favourites (ADR-056)
  • 4-screen swap + tests + e2e + budgets + docs

Out of scope

  • Deck-editor page changes beyond renameDeck
  • Card-art pipeline changes
  • Contrast / colour-blind pass (logged debt)
  • Story kebab management (deferred, T14 assumption)
  • Multiplayer, story content, canvas decoration

Halo semantics (design invariant)

blue --seat-you your pick/seat  ·  red --seat-opponent opponent pick/seat  ·  teal --accent library focus  ·  gold hairline --selected default deck, no glow

Assumptions

  • Handoff file handoff_ascencio_deck_selection_prototype_20260826-210748.md gone (/tmp wiped); plan built from committed design docs + prototype 7c34d05.
  • Persona→deck: Practice Bot→mvp-opponent, Blaze Circuit→burning-abyss, Vault Warden→shaddoll (default persona; preserves DEFAULT_OPPONENT_DECK_ID).
  • Favourites split per ADR-056: local→repository, preset→shell settings, story→save.
  • Cover art derived (extra[0] ?? main[0]), no coverCardCode schema field.
  • Mobile acceptance = Playwright narrow Chromium viewport.
  • Story kebab management deferred; story manages decks through its deck-editor route.
Implementation trap (hit once in prototype): author-origin display on a class beats built-in [hidden]{display:none}. Every floating/docked element needs an explicit .thing[hidden]{display:none} override. Regression-tested in T7.
ADRs this plan lands: ADR-055 (shared deck-select domain, boundary registration) · ADR-056 (favourite/default ownership split). Both accepted; planned until T15.
