# Explanation from reviewer B for prospective bot improvement execution

## 1. Outcome and scope

Given one target `ai-bot`, optional opponents, owner limits and possibly a compatible checkpoint, I would seek a strictly higher paired game win rate while changing only target AI. Success delivers the accepted committed source/export, verified comparison, history and report; an unchanged accepted bot is an honest outcome. This explanation describes execution without running it. Protected engine, deck, legality and hidden-information boundaries remain intact.

## 2. Process overview

The orchestrator uses the stage controller sequentially and owning tools for persisted operations. Preparation freezes the experiment and calibrates two pools. Evaluation, decision and complete loss analysis form the repeated core. Qualified isolated replay edits are assembled and evaluated; a valid regression switches to removal/update repair. Every evaluation is analyzed, including the last. Stops supersede ordinary edges; resume restores verified identities and consumed budgets.
