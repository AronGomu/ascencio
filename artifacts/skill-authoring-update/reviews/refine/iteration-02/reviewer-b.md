# Explanation from reviewer-b for candidate comprehension

## 1. Outcome and scope

Given a skill folder, produce a complete, shorter, readable sibling candidate that preserves its intended behavior, essential constraints, deterministic outputs and specified formats. Optional inputs set priorities, retained requirements, iteration count, destination and review context. Success requires the requested iterations, resolved comprehension misunderstandings, relevant validation and transparent reporting; the source remains unchanged and promotion is outside this task.

## 2. Process overview

The orchestrator reads the package and inherited authoring guidance, inventories behavior and explains the incoming skill. Each iteration simplifies the candidate, validates affected behavior, obtains three isolated explanations and repairs misunderstandings until fresh review agrees. Accounting and findings are recorded each iteration before further simplification. Dependencies are read without recursively invoking mutual review links; this review's candidate edits remain within the existing review.

## 4. Identities and invariants

| Item | Initial source/value | Allowed changes | Must remain fixed | Verification |
|---|---|---|---|---|
| Source | Supplied package | None during review | Contents, ownership | Compare source identity/content |

| Contracts | Original scripts/formats | Surrounding explanatory prose | Deterministic and specified output | Relevant checks/literal comparison |

## 5. Limits and accounting

| Resource/stage | Default limit | Override rule | Accounting | Action at exhaustion |
|---|---|---|---|---|
| Outer iterations | Five | Requested count | Per-iteration record | Deliver after completed count |
| Reduction | Aspirational 25% | Readability/preservation prevail | All agent-facing instructions, references, configuration and instructional code prose | Continue useful simplification |
| Exclusions | Executable-only inputs/source; review artifacts | Preserve honest scope | Relocation/generated instructions still count; physical size separate | Explain actual change |
| Models | Sol 6.1, low | Explicit settings/task override | Report actual controls/settings | Unavailable required review remains pending |
| Repair loop | Until no misunderstanding | Owner/session stop | Preserve review evidence | Report unreviewed corrections if stopped |
