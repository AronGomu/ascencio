# Story development themes

> Status: current owner-selected character designs and historical visual studies

This directory records the current owner-selected character designs and earlier visual experiments. Canonical character dossiers own story facts and selected visual references; this page links their current selections. Runtime asset integration remains separate.

## Structure

- Character-specific prototypes now live in `../01_DM_Era/characters/<id>/assets/references/`.
- `academy/` contains Violet Academy clothing and institutional studies.
- `shared-cast/` contains compositions involving several characters.

Some images intentionally preserve rejected directions for comparison. Their filenames and the notes below identify the usable portion of each study.
