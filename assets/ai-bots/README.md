# AI bot packages

Each bot owns one folder: Basic, Generalist, Random, or GOAT Control. `bot.json` is the package entry point and declares identity, contract version, source and distribution entries, settings, resource locations and recommended decks. Paths are package-relative; authoring can grow inside `ai/` without changing the public contract.

```text
<bot>/
├── bot.json
├── settings.json
├── evaluation.json
├── ai/
│   ├── tsconfig.json
│   ├── index.ts
│   └── evaluation/scoring.ts   # Generalist and GOAT Control
├── decks/default.ydk
├── dist/ai.mjs                 # Generated by bot:build
└── README.md
```

As real responsibilities develop, `ai/` can add `knowledge/`, `planning/`, `tactics/`, `sideboarding/`, `tests/`, `benches/` and `tools/`. Optional declared package resources can live in `data/{cards,archetypes,matchups,models}/` and `media/`. Empty placeholder modules are not required.

Run `npm run bot:build` to build all four packages, or `npm run bot:build -- goat-control` to build one. The output is a self-contained ES module exporting `createBotModule`. Include `dist/ai.mjs`, `bot.json`, settings, decks and declared resources when distributing a package. Shared game contracts, metadata adapters, legal response construction and validation are build dependencies; the distributable has no repository-relative imports.

The built-in application and evaluator use the same package sources. `evaluation.json` keeps the established builtin selectors for Basic/Generalist/Random so deterministic seeded Random and the Generalist improvement boundary remain compatible. Evaluation setup validates the manifest, uses its source entry, takes configuration from the manifest’s settings file, and checks that its deck is declared. GOAT Control selects its local module and currently starts from an independent copy of Generalist scoring.

This layout defines package authoring and build output. It does not re-enable external package discovery or installation in the application, which was retired with the Rust runtime. Campaign evidence remains under `.tmp/`; durable frozen evaluation inputs may live under `<bot>/evaluation/fixtures/`. These are not bot logic.

The retired Rust reference package lives under `docs/archive/rust-bot-experiment/reference/` and is excluded from current bot builds.

Browser development serves authored `ai/**/*.ts` modules through Vite with canonical-path checks. Package decks, data and other private content remain fenced, including source symlinks that escape into private roots.

Policy sources do not import another bot package. Generalist and GOAT Control own separate scoring implementations and reuse only the policy-independent execution SDK. Bundle tests enforce this boundary.
