# Explanation from reviewer B for prospective skill authoring

## 1. Outcome and scope

I would create or revise an agent skill from the requested task, existing package when applicable, and inferred or supplied inputs. Success means an actionable skill following the applicable template, preserving useful instructions and authorized scope, with explicit model defaults, verified references and output contracts, plus a separately delivered five-iteration refinement review. This explanation describes prospective execution; it does not initiate authoring, refinement or delegation.

## 2. Process overview

I would read the full package and mandatory ordered guidelines, then supporting writing guidance and skill mechanics. I would identify the behavior contract before drafting, apply the template selectively, validate the result, and dispatch the automatic refinement review. The reviewer would simplify a separate candidate, verify it, collect fresh comprehension explanations, correct misunderstandings and repeat for five iterations. I would report the authored result and review evidence without promoting the candidate.
