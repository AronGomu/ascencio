# Explanation from reviewer C for authoring skill comprehension

## 1. Outcome and scope

The intended result is a newly authored or revised skill that follows the annotated template, preserves useful existing instructions within the requested scope, and receives a separate automatic refinement review. Inputs are the requested behavior, destination, and any existing skill or owner decisions. Success includes a usable authored package, explicit model defaults, and an honestly reported five-iteration review candidate. Promotion is a separate later decision. This document explains execution; it does not perform authoring or review.

## 2. Process overview

Read the candidate and its ordered guidelines, then supporting writing guidance and skill mechanics. Establish behavior before editing wording, adapt the template, and verify the result. After completing authoring, delegate one refinement review for each changed skill. That child reads dependencies, records an incoming explanation, simplifies a separate package, checks it, and obtains three fresh comprehension explanations. It corrects misunderstandings and repeats verification before advancing through five iterations. Mutual dependency links require reading, while review-generated edits remain inside that review rather than starting another.
