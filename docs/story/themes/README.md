# Story development themes

> Status: non-canonical visual prototypes

This directory groups visual experiments used while developing the story, characters and art direction. Images here are reference material only. They are not approved runtime assets, package inputs or canon by themselves; the prose in the surrounding story documents remains authoritative.

## Structure

- `characters/<name>/` contains prototypes associated with one character.
- `academy/` contains Violet Academy clothing and institutional studies.
- `shared-cast/` contains compositions involving several characters.

Some images intentionally preserve rejected directions for comparison. Their filenames and the notes below identify the usable portion of each study.
