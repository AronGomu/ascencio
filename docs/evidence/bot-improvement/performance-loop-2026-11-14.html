Verified resume and reproduction

The diagnostic command creates a fresh isolated fixture, completes every mechanical report, and verifies resume automatically. Its output must be a new directory outside an existing budgeted run.

node scripts/bot-improvement/benchmark-improvement-workflow.ts \
  --source FROZEN_SESSION --out FRESH_OUTPUT --matches 25 --workers 2

For an existing session, retain its pinned source/runtime, frozen inputs, worker configuration and original limits. Check owner liveness before recovery; never clear a live lock or lease. Resume through the normal adapter:

npm run bot:matches -- --session SESSION --out SESSION/evaluation --workers auto --resume

Completed work is reverified before admission. A fully completed resume must keep game reservations unchanged and report zero newly executed games. Historical runs with older runtime identities require matching tooling. See the runner contract.
