# Explanation from reviewer A for prospective bot improvement execution

## 1. Outcome and scope

Given a target `ai-bot`, optional opponents, owner limits and possibly a compatible checkpoint, I would seek a strictly higher equally weighted paired-game win rate. Success delivers the retained accepted source, verified results and compact history; unchanged output is valid when no edit qualifies. Only target AI changes. Decks, engine, legality, hidden information and frozen opponents remain protected. This explanation executes no campaign.

## 2. Process overview

I would prepare immutable comparison inputs and calibrated execution pools, evaluate baseline, then decide and analyze every evaluated source. Eligible loss reasons lead to isolated replay variants, passing edits combine, and another evaluation closes the loop. Decision ceiling or no qualifying edit leads to delivery. Stops override every edge. The stage dispatcher prints instructions and checks edge names; owning tools persist evidence and the orchestrator verifies semantic gates.
