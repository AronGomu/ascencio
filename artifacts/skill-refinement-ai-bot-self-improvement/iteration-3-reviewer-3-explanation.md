# Explanation from reviewer 3 for refined bot-improvement skill comprehension

## 1. Outcome and scope

Given a required target package, optional opponent packages and owner limits, the orchestrator seeks a higher paired-match win rate while changing only the target AI. Completion means all intended decisions and their loss analyses are verified, comparable existing versions ranked, accepted source exported and a checked report retained. A completed search can retain the starting version if no edit validates; an exhausted run remains incomplete. This explanation reads only the refined package and explanation template; it performs no improvement execution.

## 2. Process overview

Prepare frozen identities, budgets and separate match/replay calibrations; evaluate the baseline and then combined candidates on one paired schedule; decide before delegating loss diagnosis. Each completed evaluation receives complete loss coverage. Eligible reasons lead to isolated rule variants and replay gates, then one combined candidate returns to evaluation. Strict improvement advances the accepted reference; regression selects repair from the rejected source, whereas ties/unassessable comparisons return to accepted-source additions. Completion and no validated edits lead to verification; resource exhaustion suspends instead.
