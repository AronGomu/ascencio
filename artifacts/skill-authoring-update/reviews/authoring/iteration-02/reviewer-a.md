# Explanation from reviewer A for prospective skill authoring

## 1. Outcome and scope

I would create or revise an agent skill from the user's intended task and any existing package, using the annotated template to express observable outcomes and executable decisions. Success means a usable authored skill with necessary supporting resources, preserved useful instructions and requested scope, plus a separately reported five-iteration refinement candidate. Promotion is outside this authoring task. This document describes that prospective execution; it does not perform authoring or review.

## 2. Process overview

I would first read the complete ordered guidelines and supporting writing guidance, resolving conflicts by instruction precedence and then displayed guideline order. I would identify behavior before drafting, adapt the template, verify the result, and trigger one automatic refinement review per changed skill. Its reviewer loops compare independent comprehension and repair misunderstandings; five iterations produce a separate candidate and evidence. Circular authoring references resolve to this candidate's requirements and do not recursively invoke another authoring review.
