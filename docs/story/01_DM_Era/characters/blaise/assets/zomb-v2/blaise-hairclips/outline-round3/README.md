# Outline spider — round 3

Twenty refinements of the owner's preferred **round 2, option 04: Outline charm**.
These remain flat hair-clip emblems: ivory fill, charcoal outline and a dusty-pink bow.

- 01–08 explore the body silhouette.
- 09–14 explore bow placement and treatment.
- 15–20 explore facial expression.

Use the number together with “round 3” when selecting a variant. The preferred
outline direction is recorded; no final round-3 option has been applied to the
dress, casual outfit or either uniform. Blaise's 80 cm proportion target remains
unchanged.

Each option has an original numbered PNG and an exact `NN-prompt.txt` sidecar,
generated with the built-in image tool. The [option records](options.json) retain
the names and design briefs.

Open the [comparison](comparison.html) or [standalone comparison](comparison-standalone.html).
Rebuild them from the repository root with Python and ImageMagick:

```sh
python docs/story/01_DM_Era/characters/blaise/assets/zomb-v2/blaise-hairclips/outline-round3/build-comparison.py
```
