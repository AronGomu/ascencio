Deck search shows backs

Hand zoom clipped

Key decisions (ADRs)

ADR-028 Full Control

Off (default): windows attributed to you auto-pass — chain tail yours, or empty chain + last action event yours (fallback turn player). Opponent action + activatable = always prompt. On (or Ctrl held): all auto-answers off. Session-only.

ADR-029 Prompt-attested identity

Search prompts carry own-card codes legally → target list falls back to them when projection silent. Controller 0 only. Dies with the prompt (shuffle).

ADR-030 Private pile tops

Deck + extra: card-back top both seats. GY/banished keep face-up top. Owner still browses freely.

ADR-031 Halo v2

Green/orange/red as above; neutral bare; red also on field cards during targeting, hover-only; keyboard focus ring stays neutral.

ADR-032 Zoom overlay

Fixed layer --duel-field-layer-hand-zoom:140, pointer-only, 1.6× subtle, chips above art, keyboard keeps pin flow.
