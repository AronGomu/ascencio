# Explanation from orchestrator for incoming authored skill

## 1. Outcome and scope
Improve one target AI against frozen opponents, including its starting self; deliver accepted source, paired results and history. Preserve protected game/deck/information boundaries. This review edits instructions only and executes no campaign.

## 2. Process overview
Prepare frozen setup and both calibrated pools, evaluate baseline/candidates, decide strictly paired improvement, then analyze every evaluated result. Replay eligible reason corrections in isolation; assemble passing edits and repeat within limits, or deliver retained accepted source and pending ledger. Resource incidents suspend.

## 8. Ambiguities and interpretations

The stateless controller routes tasks; it does not enforce semantic evidence or implement the cross-iteration ledger. Current-policy replay support is an execution limitation: block unsupported cases instead of claiming a valid failure. The authored skill is retained byte-for-byte during this review.

Owner-authorized incoming-baseline amendment during review: matches default is now250 total four-game matches (1000 games per evaluation), superseding the2500 input observed before the update. All other accounting formulas stay unchanged.
