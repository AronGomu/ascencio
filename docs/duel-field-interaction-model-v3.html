ADR-007 address triple (controller,location,sequence) remains join authority. v3 adds aggregation and explicit prompt order; it does not replace the address contract.

Shipped. interactionChoicesInPromptOrder(spec) is the single ordered index over card, zone, stack, global and off-field choices, deduped by id and sequenced by spec.choiceOrder (raw prompt order). The session reducer and the confirm window both read it, so a stack- or list-only choice can no longer be rejected as unknown. offFieldChoices collects cardSelection choices addressed to hand, graveyard, deck, banished, extra and leaves each one in its launcher map as well.

Card/zone halo stays where card lives. On-field-only multi-select uses floating confirm window.

Off-field

One target window lists only legal cards across HAND/GY/DECK/BAN/EXTRA (labels expand to Your/Opponent Graveyard, Banished, Extra Deck…). Counter reads n / max selected when fixed, n selected · min–max allowed for a range. Multi Confirm lives in this window; an exact 1/1 target submits on click and shows none.

Mixed

Both surfaces stay live. One session/counter includes every selected id and submits in raw prompt order.

Battle

Attack action stays card chip; Main 2 and End stay phase controls. Generic battle dialog/action-bar duplicate is forbidden.

Deadlock guard. Closing target list hides it only. Relevant highlighted hand card/pile reopens it; live selection remains. Outside click never cancels confirm.

Stack order

board surface < zones < stacks < cards < raised hovered/pinned card
              < action chips < floating windows < drag ghost
              < app modal/backdrop

Cards/list entries zoom 1.35× / 120 ms ease-out. Root scales so halo follows. Hand origin points inward. Reduced motion removes zoom/animation while leaving static colours and focus intact.

Dependency-free drag state machine

Idle→ pointerdownArmed→ >8 pxDragging→ releaseSettle target/home→ ≤600 msIdle

Pointer phase

One rAF consumes latest sample. Grab offset retained. Filtered horizontal velocity drives tilt, clamped ±10°. Scale 1.08.

Settle phase

Spring 180 / damping 24 / dt cap 32 ms. Stop ≤0.5 px + ≤8 px/s or 600 ms.

Valid release

Existing hit test resolves legal choice and submits immediately. Ghost animation is post-command feedback.

Reduced motion

Follow pointer with zero tilt. Release removes ghost immediately; command semantics unchanged.

Privacy, accessibility & validation gates

Privacy

No unknown code/name/art URL in DOM, image cache request or routine diagnostics. Raw hidden message code is never UI evidence.

Targets

Every interactive rect stays ≥44×44 px. Board minimum remains 52rem; preview/window content yields first.

Answerability

Every engine choice is on mounted target, aggregate list or global/phase control. Conflict fails visibly.

Motion

Reduced-motion path has no zoom/tilt/spring but keeps semantic state and all commands.

Windows

Both border boxes remain inside visible field after drag, reload, pan and resize.

Browser

Chromium checks actual hit testing, overlap, bounds, viewport overflow and transformed rects — not jsdom CSS assumptions.
