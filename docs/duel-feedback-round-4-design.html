Card knowledge model

One vocabulary drives board art, zoom, labels, lists, preview. Attestation source = projected PublicCard.code (ADR-014) with one addition: prompt-attested own-card codes during a selection (ADR-029).

PUBLIC

Both players know. Face-up board cards, GY/banished piles. Face-up top on stack. Zoom + label + preview.

PRIVATE

One player knows. Own hand, own set cards, own extra deck, deck during own search. Board shows back; owner gets zoom + name label + list faces.

HIDDEN

Nobody knows. Opponent hand/set, unrevealed decks. No zoom, no label, preview keeps its previous card.

Engine address fix

ocgcore reports the field-spell zone as spellTrap sequence 5. mapEngineFieldAddress now maps it to p{player}:field; sequences 6/7 stay rejected. Response encoding keeps the raw engine address, so the core round-trip is untouched. This unblocks The Grand Spellbook Tower and every field spell. (T1) The unsupported_message abort is diagnosed from the duel trace on a programmed spellbook duel and fixed at the exact unsupported message. (T2)

List dialog behavior

  • Opponent entries upright — rotation stays board-only. (T12)
  • "Select between 1 and 1 choices" removed; the 0 / 1 selected counter carries the requirement. (T12)
  • While a targeting effect resolves, clicking the haloed launcher toggles collapse (single button ⇄ full list) and can never dismiss the decision surface. (T13)

Right rail

  • Header row (turn · phase + options) with a separating rule.
  • Avatar placeholders (person silhouette, not card backs), full panel width, fat 4px border.
  • LP plate "LP 8000" (label-left, no separator), bordered, centered, tabular digits; green >4000, orange 2000–4000, red <2000; count animation on change (reduced-motion aware).
  • Status/action prompt vertically centered on the field middle. (T10)
