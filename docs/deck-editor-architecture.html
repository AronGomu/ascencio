Model & storage

  • DeckCommand: add(zone?) · remove · move · import · restore · reorder · sort(alpha|type). Append-at-end semantics; no auto-sort (ADR-037).
  • History = membership multisets. reorder/sort: no history entry, not undoable, no autosave entry.
  • ygo-story-decks v2 (ADR-038): stores decks · histories · preferences (last-opened-deck, default-deck) · autosaves (global, cap 100, {id, deckId, deckName, createdAt, main, extra, side}). Legacy prototype DB pinned at version 1 during migration.
  • Catalog: activeCatalog() joins __ACTIVE_CARD_DATA__ + __ACTIVE_CARD_TEXTS__ + __ACTIVE_IMAGE_MANIFEST__ → imageUrl = {BASE_URL}runtime/images/{code}.jpg (ADR-039).

Library screen

  • Buttons: Import Deck (renamed) · Create deck. Title/eyebrow/subtitle texts removed (h1 stays visually hidden).
  • Row halo replaces the status text: green valid · orange warnings · red errors; hover tooltip (title) lists issues.
  • Row actions: Rename · Duplicate · Export · Delete · Set default (+ Default badge). Default feeds the duel start menu (see deck-default-selection-design.html).

Boundary notes

  • Editor ↔ shell: preview panel + stage context via src/shell/index.ts only.
  • src/decks/starter-deck.ts imports the bundled player.ydk?raw (asset import, mirrors ydk-adapter.ts precedent); never exported from src/decks/index.ts (eager-chunk rule).
  • Every rendered element carries a unique kebab data-cy (enforced).
