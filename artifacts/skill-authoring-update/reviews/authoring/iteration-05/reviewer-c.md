# Explanation from reviewer C for prospective skill authoring

## 1. Outcome and scope

I would create or revise an agent skill from the user's purpose, existing package where applicable, and requested boundaries. Success means a usable skill with appropriate frontmatter, explicit model defaults, clear actions and completion criteria, preserved useful requirements, and a separately delivered five-iteration refinement candidate. This explanation describes execution; it does not perform authoring, launch reviews, or authorize promotion.

## 2. Process overview

I would first read the complete ordered guidelines and supporting writing guidance, including skill mechanics. I would establish behavioral requirements before drafting, then adapt the annotated template rather than fill irrelevant sections mechanically. After verification of the authored result, I would delegate its automatic refinement review. That child would preserve the authored package, simplify a separate candidate, conduct fresh comprehension reviews and verification during five iterations, and return evidence for delivery. Mutual references supply dependencies without recursively launching authoring reviews.
