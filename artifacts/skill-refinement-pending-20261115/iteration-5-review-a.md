# Explanation from review A for fresh skill comprehension

## 1. Outcome and scope

Improve one supplied target bot against frozen opponents, including its starting self-opponent; deliver accepted source, paired results and compact history, honestly allowing unchanged completion. Only target AI changes: decks, engine, legality and hidden-information boundaries remain protected. Optional inputs are opponents, owner limits and compatible checkpoints. Use current TypeScript sessions, project tools and source-bound evidence; publishing requires separate authorization.

## 2. Process overview

Prepare freezes identities, budgets, review policy and both calibrated pools. Evaluate baseline/candidates, Decide, then Analyze even rejected/final evaluations. Otherwise authorized Replay tests isolated corrections, Assemble combines passing edits, and repeats evaluation. No passing edit or decision ceiling delivers; incidents can suspend any stage. Controller transitions are stateless guidance: orchestrator verifies semantic gates and owning tools persist transactions.
