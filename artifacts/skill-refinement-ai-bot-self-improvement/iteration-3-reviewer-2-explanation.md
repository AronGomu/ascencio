# Explanation from reviewer 2 for refined AI bot improvement comprehension

## 1. Outcome and scope

Given a required target bot folder, optional additional opponent folders and optional owner limits, the orchestrator seeks a strictly better paired-match win rate while changing only target AI. A run may legitimately finish without improvement when no candidate validates. Successful completion means all planned candidate decisions and their loss analyses are finished, or the no-validated-candidate stop applies, and evidence is verified, comparable existing results ranked, accepted source exported and the checked report delivered. Suspension is incomplete. This explanation uses only the refined skill package and the explanation template; it performs no improvement work and does not resolve linked project implementation details.

## 2. Process overview

Preparation pins a frozen session and independently calibrated match/replay pools. Evaluation precedes decision, and diagnosis begins only after decision and complete match/reservation settlement. Diagnosis supplies loss reasons; the orchestrator creates isolated edits, validates them by exact-decision replay, combines qualifying edits and loops through full evaluation. Rejections preserve the accepted comparator: ties/unassessable results return to its analysis for additions, whereas regressions use the rejected source for removal/update repair. The final decision still receives analysis before delivery. All stages share persistent resource accounting and resumable evidence.
